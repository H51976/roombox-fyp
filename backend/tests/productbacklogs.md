# RoomBox — Product Backlogs
**Project:** RoomBox — Nepal's Room Rental Platform  
**Version:** 1.0  
**Date:** April 2026

---

## 3.8.9. Product Backlogs

The product backlog for RoomBox is a prioritised list of all user stories derived from the system requirements. Stories are classified by role (Tenant, Landlord, Admin, System), assigned a priority level (High / Medium / Low), and estimated in story points using a modified Fibonacci scale. The backlog was reviewed and refined at the beginning of each sprint.

| ID | User Story | Priority | Story Points |
|---|---|---|---|
| US1 | As a user, I want to register an account as a Tenant or Landlord using my name, email, phone, and password, so that I can access the platform. | High | 5 |
| US2 | As a user, I want to log in securely using JWT-based authentication, so that my account and data are protected from unauthorised access. | High | 5 |
| US3 | As a user, I want to verify my email address after registration by clicking a verification link, so that my account is activated and secured. | High | 3 |
| US4 | As a user, I want to reset my password via a secure email link, so that I can recover access to my account if I forget my password. | Medium | 3 |
| US5 | As a tenant, I want to search for available rooms by city, room type, and price range, so that I can find rooms that match my requirements. | High | 8 |
| US6 | As a tenant, I want to filter search results by amenities such as WiFi, Kitchen, and Parking, so that I can narrow down listings to my preferences. | High | 5 |
| US7 | As a tenant, I want to view a room's full detail page with a multi-image carousel, location, amenities, and owner information, so that I can evaluate the property before booking. | High | 8 |
| US8 | As a tenant, I want to contact a landlord via a built-in chat system from the room detail page, so that I can ask questions before committing to a booking. | Medium | 8 |
| US9 | As a tenant, I want to submit a booking request for a room, so that I can formally reserve it and proceed to payment. | High | 8 |
| US10 | As a tenant, I want to pay for my booking using the eSewa payment gateway, so that I can complete my booking digitally without cash transactions. | High | 13 |
| US11 | As a tenant, I want to view all my bookings — active, pending, and past — in a dedicated bookings page, so that I can track the status of each booking. | High | 5 |
| US12 | As a tenant, I want to track my active tenancy with a progress bar, days remaining, and next rent due date on a tracking page, so that I can manage my payments and stay duration. | High | 8 |
| US13 | As a tenant, I want to voluntarily vacate or drop a room before my tenancy expires using a modal confirmation, so that I can exit the rental on my terms. | Medium | 5 |
| US14 | As a landlord, I want to create a new property listing with title, description, location, pricing, room type, amenities, images, and tenancy duration, so that tenants can discover and book my room. | High | 8 |
| US15 | As a landlord, I want to set a tenancy duration in days when creating a listing, so that the system can automatically track when a tenant's stay expires. | High | 5 |
| US16 | As a landlord, I want to edit and update my existing property listings, so that I can keep details accurate and current. | Medium | 5 |
| US17 | As a landlord, I want a dashboard with overview statistics including total listings, occupied rooms, available rooms, and total income, so that I have a clear picture of my rental portfolio. | High | 8 |

| US22 | As an admin, I want to log into a separate admin panel using admin credentials, so that the administration area is isolated from regular user access. | High | 5 |
| US23 | As an admin, I want to view, search, and manage all registered users (Tenants and Landlords), including the ability to deactivate or reactivate accounts, so that platform integrity is maintained. | High | 13 |

| US25 | As an admin, I want to view platform-wide analytics including user growth, booking rates, room availability, and monthly revenue through charts on the dashboard, so that I can monitor the health of the platform. | Medium | 13 |

| US28 | As the system, I want to automatically prevent a tenant from booking a room that is already occupied or reserved, so that double-booking is never possible. | High | 8 |
